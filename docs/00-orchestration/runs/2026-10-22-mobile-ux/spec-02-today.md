# Spec 02: Today on a phone

*Run:* `docs/00-orchestration/runs/2026-10-22-mobile-ux/` · *Builder:* builder (Opus) · *Worktree:* yes (branched from the integration branch that already contains spec 01) ·
*Time box:* 150 minutes of agent work

## Goal
On a phone, Today reads like the artboard's list: a row is a thumb-sized checkbox, a title you can read in full, one small chip, and a single ⋮ that opens a bottom sheet with every other action. Nothing on a row depends on hover, right-click, double-tap or drag. The progress row is one button that opens the progress sheet. Every tappable thing is at least 44px, no text is under 11px, and the sheets and toasts clear the tab bar. Desktop keeps its current row anatomy, popup menu and drag-and-drop.

## Deliverables (exact paths)
1. **`src/components/planner/TaskActionSheet.tsx` (new).** A bottom sheet (same shell as `ScheduleSheet`: `fixed inset-0 z-[80]`, backdrop closes, `role="dialog"`, Escape closes, `pb-safe-nav`, drag handle on phones) listing the task's actions as 48px rows with a Material or lucide icon and a label: Edit title; Schedule… (or Reschedule…; opens the existing ScheduleSheet, which on phones also carries the duration picker); Start a block / Log time (opens `TaskProgressSheet`; only for trackable tasks, per `minTrackableMinutes`); Move up / Move down (disabled at the ends); Add subtask (root tasks only); Move to another parent (subtasks only, opens the existing picker); Mark as shallow / Mark as deep work; Hide from partner / Show to partner (only when `partnerVisible`); Abandon; Delete (last, in `text-red-400`, still routed through the existing undoable delete). Takes the task plus the same callbacks `TaskItem` already receives. Header shows the task title in full (wrapping), so a truncated row title can always be read here.
2. **`src/components/planner/TaskItem.tsx`:** on a coarse pointer (`useCoarsePointer()`) the row renders the phone anatomy: `[checkbox: 24px visual inside a 44x44 hit area] [title: text-[15px] leading-snug, line-clamp-2, no truncate] [one chip: the schedule time if `scheduledAt`, else the duration if set, 12px, `bg-share-hairline`, 32px tall] [⋮ 44x44 → TaskActionSheet]`. No arrows, no grip, no duration `<select>`, no drag attributes, no `onContextMenu`, no `onDoubleClick` on phones. Subtasks are the same anatomy indented 24px.
